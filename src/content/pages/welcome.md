## Getting Started

Drop any Markdown files inside `src/content/pages/` and they will automatically become routes on your site.

### Frontmatter

Each file should include a frontmatter block like this:

```md
---
title: "Your Page Title"
description: "Optional short summary."
published: 2024-01-01
updated: 2024-01-15
heroImage: "/path-or-url-to-image.jpg"
---
```

### Writing Content

You can use standard Markdown syntax including **bold**, _italics_, lists, code fences, and block quotes. Headings automatically appear in the on-page table of contents.

> Tip: Add more headings to generate navigation links in the sidebar.

#### Lists

- Organized thoughts
- Quick outlines
- Action items
