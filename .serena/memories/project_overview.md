# Project Overview

## Purpose
Personal portfolio website for Justin High (QA Analyst & Automation Engineer) showcasing experience, skills, aviation interests, and contact information. The site serves as a professional online presence deployed at novafluxx.org.

## Tech Stack
- **Framework**: Astro 5.16.2 (Static Site Generation)
- **Styling**: Tailwind CSS 4.1.17 (integrated via @tailwindcss/vite plugin)
- **Package Manager**: pnpm
- **Language**: TypeScript (strict mode)
- **Deployment**: Cloudflare Workers (custom domains: novafluxx.org, www.novafluxx.org)
- **Icons**: Font Awesome 7.0.1 (loaded from CDN)
- **Fonts**: Google Fonts (Inter)

## Key Features
- Dark mode by default
- Glassmorphism design aesthetic
- Responsive navigation
- File-based routing
- Custom 404 page
- Static site generation with Cloudflare Workers deployment
